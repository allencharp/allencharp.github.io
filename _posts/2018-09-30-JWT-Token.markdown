# What is JWT

First, take a look at this [JWT debugger](https://jwt.io).

Simply put, a JWT is a string with the following format:

```
header.payload.signature
```

## Header

{% highlight json %}
{
  "typ": "JWT",
  "alg": "HS256"
}
{% endhighlight %}

`typ` is of course JWT, and the signing algorithm here is **HS256 (HMAC-SHA256)**.

## Payload

The payload component is the data stored in the JWT. There are some optional claims, such as `iss`, `sub` and `exp`:

{% highlight json %}
{
  "userId": "1101001",
  "name": "Allen",
  "exp": 1547078400
}
{% endhighlight %}

> Note: `exp` is a [NumericDate](https://tools.ietf.org/html/rfc7519#section-2) (Unix timestamp), not a date string.

## Signature

The JWT signature is computed roughly like this:

{% highlight javascript %}
data = base64urlEncode( header ) + '.' + base64urlEncode( payload )
hashedData = hash( data, secret )
signature = base64urlEncode( hashedData )
{% endhighlight %}

# How does JWT protect data

Most importantly, JWT is **not** a way to *encrypt* the data — it is a way to prove the data was created by an authentic source, so the data can be easily decoded and read.

**JWT does not guarantee any security for sensitive data. Do not save sensitive data in a JWT.**
